# Целевой интерфейс

## Основная идея

Интерфейс должен быть быстрым, спокойным и понятным. Пользователь нажимает `Print Screen`, выделяет область и сразу получает маленькую панель с нужными действиями.

Панель не должна выглядеть как кабинет настроек. Это инструмент на одну задачу: быстро отметить скриншот и сохранить или скопировать.

## Главный сценарий

1. Пользователь нажимает `Print Screen`.
2. Экран затемняется.
3. Пользователь выделяет область.
4. Рядом с областью появляется компактная панель.
5. Пользователь рисует стрелку, пишет текст или замазывает часть изображения.
6. Пользователь нажимает сохранить или копировать.
7. Окно закрывается.

## Инструменты первого экрана

- Стрелка.
- Текст.
- Рамка.
- Замазать.
- Отмена.
- Копировать.
- Сохранить.

## Что убрать из основного режима

- Загрузку в интернет.
- Лишние формы.
- Лишние способы экспорта.
- Большие меню.
- Редкие инструменты, которые мешают глазу.
- Непонятные подсказки, которые появляются каждый раз.

## Поведение файлов

Сохранение должно быть предсказуемым:

- папка задана заранее;
- имя файла понятно по дате и времени;
- после сохранения файл реально лежит на диске;
- если включён Яндекс Диск, синхронизация происходит уже как обычная синхронизация папки, а не как отдельная логика скриншотера.
