# Технические шаги Windows

## Сначала доказать сборку

Перед изменением интерфейса нужно собрать исходный Flameshot на Windows. Это отдельный первый результат проекта.

Нужно проверить:

- какой компилятор нужен;
- какая версия Qt нужна;
- какие зависимости нужны;
- собирается ли проект из чистого клона;
- запускается ли собранный файл;
- работает ли выбор области.

## Что проверить в коде

Найти места, которые отвечают за:

- регистрацию `Print Screen`;
- панель инструментов на экране захвата;
- список кнопок;
- сохранение файла;
- копирование в буфер;
- загрузку в интернет;
- настройки пользователя.

## Первые изменения в коде

После успешной сборки:

1. Скрыть лишние кнопки панели.
2. Отключить загрузку в интернет из основного режима.
3. Жёстко задать папку сохранения для первого рабочего варианта.
4. Проверить, что снимок сохраняется в `C:\YandexDisk\Documents\Screenshots`.
5. Проверить, что `Print Screen` открывает именно наш вариант.

## Что не делать на старте

- Не переписывать весь скриншотер сразу.
- Не менять ядро захвата экрана до проверки сборки.
- Не ломать поддержку других систем, пока задача Windows не доказана.
- Не копировать внешний вид Joxi один в один.
