# Правила проекта

1. Общаться с пользователем по-русски простыми словами.
2. В коде использовать английские имена и короткие английские комментарии.
3. Не копировать закрытый код Joxi.
4. Не копировать внешний вид Joxi один в один.
5. Делать изменения маленькими проверяемыми шагами.
6. Перед изменением интерфейса сначала доказать сборку оригинального проекта на Windows.
7. Главная рабочая цель: простой скриншотер с понятным сохранением и минимальной панелью.
